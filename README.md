# Design Goals Interiors — GitHub Pages

A responsive one-page interior design website for Design Goals Interiors, Bengaluru.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `designgoals-interiors`.
2. Upload **all files and the `images` folder** from this folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide your free `github.io` website address.

## Customize

- Main content is in `index.html`.
- Styling is inside `index.html` in the `<style>` section.
- Project photos are in `images/`.
- The logo is `logo.svg`.
- Replace the phone number, text, or photos in `index.html` whenever needed.

## Important

The website uses Google Fonts from fonts.googleapis.com. Everything else is local, so the project can be hosted directly on GitHub Pages.
